# Admin Guide

Use `/admin/` with the superuser. Configure Website Settings for phone, email, address, logo, Google Maps link/embed URL, social links and hero text. Admission Settings controls the homepage admission badge. Statistics controls homepage numbers. Study Mode Info controls the Regular/ODL section.

Course workflow: category → verified university → course → fee/duration/study modes → admission status → active/featured.

Use Inquiry and Career Consultation admin screens to search/filter submissions and update statuses. Publish testimonials only after client approval. FAQs are controlled by active/display order. Site Pages holds About, Privacy Policy and Terms. Franchise Applications are reviewed in Admin; franchise users cannot access Admin.
